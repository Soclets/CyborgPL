# The 2026-10-07 revision: old spelling → new

The owner, 2026-10-07: "Feeling like a syntax revision right now, likely not gonna be removing,
but adding for clarity." Every ruling, with the owner's words, is in `DECISIONS.md` under
2026-10-07. This page is the lookup table. Built in the oracle the same day; every example and
test is written in the new syntax. The old spellings are refused everywhere, each naming its
replacement, MTM (which kept other spellings) being gone ("MTM is gone.").

Code blocks in the other design notes were converted; their prose may still name an old
spelling where it records history.

## Spellings

| Was | Now |
|---|---|
| `-->`, `<--`, `<-->` (and `>>`, `<<`, `<->`… as MTM's) | `->`, `<-`, `<->` ("Short, the neck & eye movement is less") |
| `!mut` | `immut` |
| `!check` / `nocheck` | `no_check` |
| `!cheat` | `no_cheat` |
| `!$` | `no_shadow` |
| `! 'x'` | `not 'x'` |
| `==` | `equal_to` |
| `!==` | `not_equal` |
| `</==`, `>/==` | `at_most`, `at_least` (`<`, `>` stay) |
| `!std.int24` | `not_std.int24` |
| `std::` | `stdkit::` (still `bare.optional`); since 2026-10-09 `cord::` (Nerve's name for it) |
| `\n` outside text | `newln` |
| `print.useful.auto_newline` | `print.useful.auto_newln` |
| `giveS` (in `#strict`) / a bare value in a case | `is "free";` |
| `inline.Assembly`, `inline.S` | `inline.ASM` |
| `let 'x' $:= 2;`, `let 'x': T $= 2;` | `shadow 'x' := 2;`, `shadow 'x': T = 2;` (2026-10-08) |

## Clarity

| Was | Now |
|---|---|
| `range[1, 4]`, `range[1, 4, 2]` | `range[from 1, to 4, by 1]`, `by` always written |
| `'xs'[2]` | `'xs'[pos 2]`, and `pos` on every position: `list.slice[lend 'xs', pos 2, pos 3]`, `list.remove[lend.mut 'xs', pos 1]`, `str.at.grapheme[lend 's', pos 3]`, `str.slice.grapheme[lend 's', pos 1, pos 4]` (2026-10-08) |
| `list.fill[0, 10]` | `list.fill[value 0, count 10]` |
| `simd.fill[0]` | `simd.fill[value 0]` |
| `print.useful.stdout[…]` | `print.useful[…]`: stdout unless `.stderr` (`.stdout` may still be written) |
| — | `format[…]`: the text `print.format` would print |
| `fn f ['n'] { return 'n'; }` | every parameter and return typed: `fn f ['n': int32] -> int32` |
| `fn max <T>: Number […]` | `fn max <T: Number> […]`, one `< >` with commas: `<A: any, B: Hashable>` |
| `fn pick <T>: any \| @x […]`, `fn two @x @y […]` | `fn pick <T: any> [@x, @y] […]` |
| `lent@x` | `lent @x` |
| `pub.limb` | `pub.neuron`: a library is a Neuron (2026-10-09; the root file `neuron.nrv` becomes `neuron.nrv` with the file endings) |
| `cores = [cca::Core[…]]` in `CCA.cplr` | `lobes = [kin::lobe[…]]`: a core is a lobe (2026-10-09) |
| `.cpls`, `limb.cpls`, `CCA.cplr`, `cca::Manifest[…]`, `tune.cplr` | `.nrv` for code, `neuron.nrv`, `Kinesin.nrp`, `kin::manifest[…]`, `tune.nrp`: `.nrp` for a file that is one value and never runs (2026-10-09) |
| `-> lent T` with two borrowed inputs | needs a group: `-> lent @x T` (with one input it is inferred) |
| `#strict` | gone; what it wrote out is every file's |
| `paid { match 's' { … } }` as the case's value | `paid { is match 's' { … }; }` |

## Unchanged on purpose

`[ ]` for calls, building, indexing; `lend` / `lent`; `:=` ("it's fucking iconic, bro");
`and` / `or` beside `and.then` / `or.else`; the working build's run-time checks; `temp` the
default (and may be written); `mut` only where a variable changes (`immut` may be written).

## What left the base (lobes)

| Thing | Lobe |
|---|---|
| `test fn`, `must` | TAS, "Test And Shit" |
| `brain16` | AI |
| `int128`, `uint128`, every `not_std.` width | WSMW, "Weirdly Small And Massive Widths" |
| `deci32/64/128` | Money |
| `str.utf16/32`, `char.point`, `char.grapheme`, counting in points or graphemes | UniTect |
| `case.any` / `case.exact` (`case.insensitive` / `case.sensitive` until 2026-10-10) | CAPS, "Capitals Are Pretty Similar" |
| range types and length bounds | ASP |

IDs are in `cores.md`. A Neuron whose `Kinesin.nrp` does not list the lobe is refused, naming it; a
lone file gets every core. The base keeps integers 8 to 64 bits, `bin`, `bool`, `char.byte`,
byte text, arrays, SIMD (by lane count; a width the target lacks refused, a fallback written by
hand with `on.target` / `on.machine`), pointers, structs, enums, functions and the rest.
