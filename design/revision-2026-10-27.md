# The redesigns of 2026-10-26 and 2026-10-27 — old spelling → new

> The rulings are DECISIONS.md's "Redesign: …" entries (2026-10-26 night and 2026-10-27) and "Redesign two: …"
> (2026-10-27 evening: the words abbreviated aggressively, the structure kept). This table is for reading old code: the
> code in this repository is in redesign two's spellings, and every older one is refused by name (`spellings.cyr`,
> `since = "2026-10-27"`). `oracle --redesign <file | folder>` rewrites a program from before the redesigns;
> `oracle --redesign-shorten` one in redesign one's long words (the morning of 2026-10-27). Picks marked *provisional*
> are design claude's, where the rulings say nothing (oracle/README.md lists them).

## Blocks

| old | new |
|---|---|
| `fn add [$a: i32] -> i32 { … }` | `fn add [let $a: int.sign.32] -> int.sign.32:` … `end of fn add` (no effects); `proc` … `end of proc` with them |
| `if $c > 0 { … } else if … { … } else { … }` | `if $c gt 0:` … `else if …:` … `else:` … `end of if` (one block, `end of if` once) |
| `match $a { calm { … } hot $l { … } }` | `match $a:` / `case calm:` … `end of case calm` / `case hot $l:` … `end of case hot` / `end of match` |
| `let $r := match $a { … };` | `let $r := match $a:` … `end of match;` |
| `f(…) otherwise { bad_row $w { continue; } };` | `f(…)-` / `otherwise:` / `!case bad_row $w:` … `!end of case bad_row` / `end of otherwise;` (`!` on an arm that jumps; the call's line ends `-`) |
| `MAIN { … }` | `!MAIN:` … `!end of MAIN` |
| `struct Line { name: str.utf8, immut count: i32 }` | `rec Line:` / `var name: str.utf8;` / `let count: int.sign.32;` / `end of rec Line` (every field says `let` or `var`) |
| `enum Status { empty, claimed: str.utf8 }` | `union.tag Status:` / `empty;` / `claimed: str.utf8;` / `end of union.tag Status` |
| `%layout.C enum Key { a = 65 }` | `%layout.C enum Key:` / `a = 65;` / `end of enum Key` |
| `no_check inline.ASM { … } with [$a -> x0];` | `!no_check inline.ASM with [$a -> x0]:`, the code, `end of inline.ASM` |
| `%concur with [lend $c] { … }` | `%spawn.task with [lend $c]:` … `end of %spawn.task` (`%spawn.task.detached`) |
| `coll.fn area { … }`, `coll.handler h { … }`, `coll.bound trip { … }` | `coll.fn area:` (or `coll.proc`), `coll.handler h:`, `coll.bounded trip:`, each `end of` its kind and name |
| a member, `area.square [ … ] { … }`, `greet.hi [ … ];` | `member area.square [ … ]:` … `end of member area.square`, `member greet.hi [ … ];` (a template's: `member [ … ]:` … `end of member`) |
| `no_check { … }` | `!no_check:` … `!end of no_check` |
| `{ … }` alone | `block:` … `end of block` |

Commas inside brackets, semicolons inside blocks: fields, cases and an interface's types each end with `;`.

## Words

| old | new | old | new |
|---|---|---|---|
| `let` that changes, `let mut` | `var` | `let immut` | `let` (never changes) |
| `let $x: i32 = 5;` | `let $x: int.sign.32 := 5;` (a definition `:=`) | `change $x = 6;` | `change $x to 6;` |
| `let mut $n := 0;` | `var $n = 0;` (a starting value `=`, typed or not) | | |
| `shadow $x`, `shadow mut $x` | `let shadow $x`, `var shadow $x` | `'total due'`, `'x'` | `$'total due'`, `$x` |
| `struct` | `rec` | `enum` | `union.tag` (C's: `enum`) |
| `interface` | `sig` (a signature) | | |
| `return` | `ret` | `concur` | `spawn.task` |
| `no_check` | `!no_check` | `no_cheat` | `no_skip` |
| `+` `-` `x` `xx` `<` `>` | `plus` `minus` `times` `pow` `lt` `gt` | `-5`, `-$x` | `neg 5`, `neg $x` |
| `equal_to`, `not_equal` | `eq`, `not_eq` | `list`, `array` | `ls`, `arr` |
| `mut` (a declaration) | `var` | a field, `immut` field | `var x: T;`, `let x: T;` |
| a parameter `[$a: T]`, `[mut $a: T]` | `[let $a: T]`, `[var $a: T]` (`lent` / `lent.mut` as they were) | | |

Kept as they were before the redesigns: `fn`, `op`, `const`, `pub`, `coll.`, `ptr`, `incl.`, `extern.C`, `str`, `bool`,
`char`, `concat`, `div.` / `mod.` (`.near`, `.trunc`, `.ceil`), `shl` / `shr`, `bin` / `hex` / `oct`, `min:` / `max:` /
`pos:`, `newln`, `secs` / `mins` / `millis`, `cols`, `lend.mut`, `seq` / `para` / `temp` / `perm`.

## Number types

`i8` … `i128` → `int.sign.8` … `int.sign.128`; `u8` … → `int.unsign.8` …; `f16` / `f32` / `f64` → `float.bin.16` …;
`d32` / `d64` / `d128` → `float.deci.32` …; `brain16` → `float.brain.16`. A limb's mark goes on the part it adds:
`%d64` → `float.%deci.64`, `%brain16` → `float.%brain.16`, `%i128` → `int.sign.%128`.

## The checks that came with it

- A `fn` has no effects (no print, input, wait, exit, task, channel, C, pointer, another language's code, no changing what
  it was lent) and calls only `fn`s; one that can fail is still a `fn`. A `proc` may have effects.
- A `let` never changes; something changing one is refused, naming `var`. A `var` nothing changes is refused.
- Every `end of` line names the kind and name its block opened with; `!` stands exactly where something needs attention:
  `!MAIN`, every `!no_check`, a handler arm that jumps (`ret`, `break`, `continue`), and that handler where it is used
  (`otherwise half_failed.!as_zero`).
