# The redesign of 2026-10-26 and 2026-10-27 — old spelling → new

> The rulings are DECISIONS.md's "Redesign: …" entries (2026-10-26 night and 2026-10-27), each with the owner's words.
> This table is for reading old code: the code in this repository is in the new spellings since 2026-10-27, and every
> old one is refused by name (`spellings.cyr`, `since = "2026-10-27"`). `oracle --redesign <file | folder>` rewrites a
> program. Picks marked *provisional* are design claude's, where the rulings say nothing (oracle/README.md lists them).

## Blocks

| old | new |
|---|---|
| `fn add [$a: i32] -> i32 { … }` | `function add [$a: integer.signed.32_bit] -> integer.signed.32_bit:` … `end of function add` |
| `if $c > 0 { … } else if … { … } else { … }` | `if $c greater_than 0:` … `end of if`, then `else if …:` … `end of else if`, `else:` … `end of else` |
| `match $a { calm { … } hot $l { … } }` | `match $a:` / `case calm:` … `end of case calm` / `case hot $l:` … `end of case hot` / `end of match` |
| `let $r := match $a { … };` | `let $r := match $a:` … `end of match;` |
| `otherwise { bad_row $w { continue; } }` | `otherwise:` / `!case bad_row $w:` … `!end of case bad_row` / `end of otherwise` (`!` on an arm that jumps) |
| `MAIN { … }` | `!MAIN:` … `!end of MAIN` |
| `struct Line { name: str.utf8, count: i32 }` | `record Line:` / `name: string.utf8;` / `count: integer.signed.32_bit;` / `end of record Line` |
| `enum Status { empty, claimed: str.utf8 }` | `union.tagged Status:` / `empty;` / `claimed: string.utf8;` / `end of union.tagged Status` |
| `%layout.C enum Key { a = 65 }` | `%layout.C enumeration Key:` / `a = 65;` / `end of enumeration Key` |
| `no_check inline.ASM { … } with [$a -> x0];` | `!no_check inline.ASM with [$a -> x0]:`, the code, `end of inline.ASM` |
| `%concur with [lend $c] { … }` | `%spawn.task with [lend $c]:` … `end of %spawn.task` (`%spawn.task.detached`) |
| `coll.fn area { … }`, `coll.handler h { … }`, `coll.bound trip { … }` | `collection.function area:` (or `collection.procedure`), `collection.handler h:`, `collection.bounded trip:`, each `end of` its kind and name |
| `no_check { … }` | `!no_check:` … `!end of no_check` |
| `{ … }` alone | `block:` … `end of block` (*provisional*) |
| a long call `f(…) otherwise {` | `f(…) otherwise:` on the same line, or `f(…)-` and `otherwise:` on the next |

Commas inside brackets, semicolons inside blocks: fields, cases and an interface's types each end with `;`.

## Number types

`i8` … `i128` → `integer.signed.8_bit` … `integer.signed.128_bit`; `u8` … → `integer.unsigned.8_bit` …; `f16` / `f32` /
`f64` → `float.binary.16_bit` …; `d32` / `d64` / `d128` → `float.decimal.32_bit` …; `brain16` → `float.brain.16_bit`.
A limb's mark goes on the part it adds (*provisional*): `%d64` → `float.%decimal.64_bit`, `%brain16` →
`float.%brain.16_bit`, `%i128` → `integer.signed.%128_bit`.

## The checks that came with it

- A `function` has no effects (no print, input, wait, exit, task, channel, C, pointer, another language's code, no
  changing what it was lent) and calls only functions; a function that can fail is still a function.
- A `let` never changes; something changing one is refused, naming `variable`. A `variable` nothing changes is refused,
  as a `mut` was.
- Every `end of` line names the kind and name its block opened with; `!` stands exactly where something needs attention:
  `!MAIN`, every `!no_check`, a handler arm that jumps (`return`, `break`, `continue`), and that handler where it is used
  (`otherwise half_failed.!as_zero`).
