# Redesign three (2026-10-27/28): redesign two → the one spelling

> The rulings are DECISIONS.md's "Redesign three (EXPLORING, NOT BUILT): …" entries (2026-10-27 night and 2026-10-28),
> built on the owner's "done, build it" (2026-10-28). This table is for reading redesign two's code: the code in this
> repository is in redesign three's spellings, and every redesign-two spelling is refused by name. `oracle --redesign`
> takes a program from before the redesigns to redesign two, and `python3 oracle/tools/redesign_three.py` takes redesign
> two to three; `oracle/tools/plain_verbs.py` then takes the `copy` off a plain union's values. Picks marked
> *provisional* are design claude's (oracle/README.md lists them).

The direction (owner): "concise where possible", "where it should stay words, should stay words", and then "drop it" to a
second, all-words style: **one spelling**. Where a symbol was chosen it is the symbol; where none was, the word.

## Blocks and marks

| redesign two | redesign three |
|---|---|
| `fn add […]:` … `end of fn add` | `fn add […]:` … `;fn add` (the kind and the name, as before) |
| `if …:` … `else:` … `end of if` | `if …:` … `else:` … `;if` |
| `!MAIN:` … `!end of MAIN` | `MAIN:` … `;MAIN` |
| `!no_check:` … `!end of no_check`, `!no_check let …` | `no_check:` … `;no_check`, `no_check let …` |
| `!case too_far:` … `!end of case too_far` (an arm that jumps) | `case too_far:` … `;case too_far` |
| `otherwise booking_failed.!explain(…)` | `otherwise booking_failed.*explain(…)` (`*` only where a jumping handler is used) |
| `!no_check inline.ASM with […]:` … `end of inline.ASM` | `no_check inline.ASM with […]:` … `;inline.ASM` |

`!` has no meaning any more (owner: "I'm feeling like removing that `!` meaning"); `*` has no word, being a mark as `$` is.

## Operators

| redesign two | redesign three | redesign two | redesign three |
|---|---|---|---|
| `plus` | `+` | `eq` | `==` |
| `minus` | `-` | `not_eq` | `!=` |
| `times` | `x` (not `*`) | `lt`, `gt` | `<`, `>` |
| `pow` | `std::pow` (`^` until later on 2026-10-28) | `at_most`, `at_least` | `<=`, `>=` |
| `neg 5`, `neg $x` | `-5`, `-$x` | | |

`and`, `or`, `and.then`, `or.else` and `concat` keep their words (owner, 2026-10-28: "we already have `and` & `or` narrowings"); `&&` and `||` are
old spellings. Words only, as before: every narrowing (`plus.wrap`, `times.wrap`, `std::pow.wrap`, `div.floor`, `mod.near`, the `.ieee`
forms), `div.X`, `mod.X`, `not`, `xor`, `shl` / `shr`, the bit operators (`and.bit`, `or.bit`, `xor.bit`, `not.bit`).
Negation as a value is `op neg` (owner, 2026-10-28: "keep it"), `op -` being subtraction. `x` is multiplication between two values; a function or type may be named `x`, reached as `my.x(…)` (owner, 2026-10-28), and a
field may be `x`: `$p.x`, `var x: f64;`.

## Failures, changes, printing

| redesign two | redesign three |
|---|---|
| `let $km := parse_km(lend $row) otherwise fail;` | `let $km := parse_km(lend $row)?;` |
| `let $n := std::map.get(…) otherwise 0;` | `let $n := std::map.get(…) ?? 0;` |
| `change $total to $total plus $fare;` | `change $total to $total + $fare;` (`+=` and its family tried and dropped, 2026-10-28) |
| `std::print.shortest(…, newln);` | `std::print(…, newln);` (`print.shortest` stays its full name) |
| `print.shortest.auto_newline` | retired: `std::print(…, newln)` |

`?` and `??` stand where `otherwise` can: ending a call that is the whole statement or right-hand side. `otherwise` stays
for arms (`otherwise:`) and named handlers. A line ends with `newln`, in every printing form: `std::println` was tried and
dropped (owner, 2026-10-28: "drop"), one way to end a line being more consistent than two.

## Number types

| redesign two | redesign three |
|---|---|
| `int.sign.8` … `int.sign.64`, `int.sign.%128` | `i8` … `i64`, `%i128` |
| `int.unsign.8` … `int.unsign.%128` | `u8` … `%u128` |
| `float.bin.16` … `float.bin.64`, `float.bin.%128` | `f16` … `f64`, `%f128` |
| `float.%deci.32` … `float.%deci.128` | `%d32` … `%d128` |
| `float.%brain.16` | `%bf16` |
| `int.sign.%not_std.24` | `%not_std.i24` |

The one exception to "`.` narrows", a closed list: a type a limb adds is named with dots, `%quantum.ezeral.32`, a unit
suffix its writer's choice.

## Ownership

A `union.tag` whose every case holds no data is plain, as a number is: passed bare and copied, `copy $r.age` refused.

## Kept as they were

`let` / `var` on every declaration (owner: "no `let` there would make it inaccurate"), `:=` / `=` / `change … to`,
`lend` / `lent` / `give` / `copy`, `.mut` on borrows and pointers, `std::` on another kit's names, `sig` / `set`,
`%layout.C` on its closer, the line-end `-` before a block's opening line.
