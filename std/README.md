# std — CyborgPL's standard library, in CyborgPL

Written by std claude (`design/std-session.md`). std is CyborgPL calling the runtime (Rust) only for
what CyborgPL cannot say yet (owner, 2026-09-14; again 2026-10-14, "(c)"). Other kits write its names with
`std::`, or bring one in with `use std::… as …;` (owner, 2026-10-22). It was `cord/`, Nerve's cord, until the sweep to Zag's
names (2026-10-15), and took CyborgPL's names in the next sweep (2026-10-16). It is written in redesign three's
spellings since 2026-10-29 (`oracle --redesign`, then `oracle/tools/redesign_three.py`, then the fixes below by hand;
the table is `design/revision-2026-10-27.md`).

Every function std offers is a `fn`, with no effects (owner, 2026-10-27): its helpers change only what they are
lent (`lent.mut $out`), which is no effect (owner, 2026-10-29: "(a)"), and where std finds a bug in itself it stops
with `bug "…"`, which is none either (owner, 2026-10-29).

## What is here

- `kit.cy` — the root: what other kits see is written `std::…` (owner, 2026-10-22).
- `str.cy` — `std::str.contains`, `starts_with`, `ends_with`, `split`, `join`, `replace`
  (`design/strings.md`; the argument words are `spellings.cyr`'s). They work on the bytes and call
  nothing in the runtime. Their `part`, `at` and `from` are texts of at least 1 byte, `str.utf8[min: 1
  bytes]` (owner, 2026-10-14: "Error"), so an empty one is refused when building, or checked where it
  is passed if it is worked out at run time. The oracle's built-in std refuses it when the call runs:
  the same rule, met at a different moment. `std::str.at.byte(lend $s, pos: 2)` is the byte at a
  position (a `u8`), `std::str.at.point(lend $s, pos: 2)` the character (a `char.%point`) and
  `std::str.at.cluster(lend $s, pos: 2)` the grapheme cluster (a `char.%cluster`), each failing `out_of_range`
  past the last one (owner, 2026-10-17: str.at next; 2026-10-20: "(a)", finish str.at and str.slice).
  `std::str.slice.cluster(lend $s, from: pos 2, to: pos 4)` and `str.slice.point` are the part from one
  position to another, both kept, or `before: pos 5` to leave the end out (2026-10-12); they fail
  `out_of_range` when the end comes before the start or past the last unit, so a slice is never empty,
  as the oracle's does. `std::str.slice.byte(lend $s, from: pos 1, to: pos 5)` gives the bytes, a
  `ls[u8]`, not text, since an end may land inside a character; text from them is the caller's
  `to.str.utf8(lend $b) ?? …` (owner, 2026-10-20: "(a)"). A position is
  `u64[min: 1]` (owner, 2026-10-17: "(a)"): a written `pos: 0` is refused when building, and a position
  worked out while running is proven or converted where it is passed (`to.u64[min: 1]($i) ?? 1`),
  so `out_of_range` means only past the end.
- `std::str.upper.ascii(lend $s)` and `str.lower.ascii` change a to z (or A to Z) only, every other byte as it
  is (`café` is `CAFé`); `str.upper.simple` and `str.lower.simple` give each character its Unicode simple
  mapping, one for one (`ß` stays `ß`). `str.upper.full` and `str.lower.full` are Unicode's full mappings:
  SpecialCasing's longer ones where there is one (`straße` is `STRASSE`, `ŉ` is `ʼN`, `İ` lowers to `i̇`),
  and a `Σ` ending a word lowers to `ς`, Final_Sigma as the Standard writes it: a letter both cased and
  case-ignorable counts as cased, so `ʰΣ` is `ʰς` and `ΑΣʰ` is `ασʰ` (owner, 2026-10-24: "isn't Unicode
  says what correct?"; ICU, Rust and Python give `ʰσ`). `.full(lend $s, lang: std::casing.tr)` adds a language's own rules
  from SpecialCasing, with their conditions as Unicode writes them (The Unicode Standard, 3.13): `tr` and
  `az` (`i` is `İ`, `I` is `ı`, `İ` is `i`), `lt` (a dot kept or added on `i`, `j`, `į` before an accent
  above, and taken off after them when uppercasing); `root` is every other language. `kit.cy` holds
  `pub union.tag casing:` with the cases `tr;`, `az;`, `lt;` and `root;`, one to a line (owner, 2026-10-20).
- Bytes cut on a character's edge become text with `to.str.utf8(lend $bytes) ?? bug "…"`, and a rounded number's
  digits read back the same way: the failure cannot happen, so reaching it is a bug in std, which stops the program
  with exit 101 and `error[bug]` (owner, 2026-10-29). Until then std printed `std: a bug: …` and called
  `std::exit(code: 101)` (2026-10-14, provisional), which made those functions procedures.
- `case_tables.cy` — Unicode 17.0.0's case tables as sorted consts, each searched by halves written out
  step by step, generated by `tools/case_tables.py` from Unicode's own files (owner, 2026-10-21: "(a)";
  rerun when kayo's Unicode moves). Unicode's data is under the Unicode License v3,
  `tools/UNICODE-LICENSE`.
- `round.cy` — rounding, one family (owner, 2026-10-17; overloading 2026-10-20): `std::round.near` (a tie
  to even), `round.half_up` (a tie away from zero), `round.floor`, `round.ceil`, `round.trunc`, each `($x)`
  for a whole number or `($x, places: N)`, one version per type (f16/32/64, %d32/64/128), and the
  answer is the kind that went in. A bin is rounded from its exact stored digits and read back as the
  nearest bin of its width; a deci keeps the places it is rounded to (`2.500`) as far as its digits go. A
  bin too big to have a fraction (from 2 to the power of its fraction bits) or a deci too big to have
  places comes back as it is. A bare literal fitting several versions is refused at the call (owner,
  2026-10-20: (b)): `std::round.half_up(2.5: f64)`.
- What a limb adds is marked `%` (owner, 2026-10-26; design/cores.md): Money's `%d32`, `%d64`, `%d128`,
  unicode's `char.%point` and `char.%cluster`; std's own names after `std::` never are.
- `CyJet.toml` lists the `unicode` limb, std's first, since `char.%point` is unicode's (owner, 2026-10-17:
  "(a)"), and the `Money` limb, for the decis (owner, 2026-10-20: "(a)"). A program using std does not
  inherit them: `argument_words` lists no limb.

A program uses this std, the folder it is written in, by listing it in its `CyJet.toml` under `my kits:` as
`std {` / `path = …/std` / `}` (owner, 2026-10-14; CyJet.toml since 2026-10-22). A
lone file built by KAYO uses it too, as the installed std's stand-in. Then every `std::` in the build is
this one, and what it does not define yet, `print` and `exit`, is still KAYO's Rust (owner, 2026-10-14:
"(a)").

## How it is checked

The checks are in `tools/checks/` (owner, 2026-10-26: std's tests are committed). With kayo and the oracle built
(`cargo build --release -j 3` in each), run `check.sh`, `more.sh`, `case.sh` and `sweeps.sh` there; they write to
the clone's git-ignored `.std-checks/`, where `sweeps.sh` also reads Unicode 17.0.0's files (`ucd-17.0.0/`). Each
comparison runs a std call three ways: the oracle's built-in std, a copy of this folder in the oracle (as
`stdtest`), and this folder through kayo. The fixed test programs are in `programs.py`, not `.cy` files, since
every `.cy` under `std/` is a module of the kit.

Rerun 2026-10-29 in redesign three (oracle 95b167ad, KAYO 84545791), every count as before: text 820, at 118, slice
356, slice.point 304 and slice.byte 807 against Python, round 4,795, case 756, sigma 3,264 (0 wrong against Table
3-17), dots 1,906, and std's sites in the command-line programs 556, 84 and 24, all proven with the inputs counted;
`argument_words` and `inventory` print their `.out`. KAYO did not have the owner's ruling that changing what a
function was lent is no effect yet, and refused std's three `lent.mut` helpers as `fn`s, so its builds read a copy
of this folder with them, and `upper` and `lower`, as `proc`s (`STD=…/std sh check.sh`; `common.sh` lets `STD` stand in
for this folder). check claude's corpus program in `more.sh` waits for check claude's conversion.

- `examples/argument_words.cy` and `examples/inventory.cy`, unchanged, built by KAYO against this
  folder, print their `.out`, every one of their sites proven; so do `round.cy`, `whole.cy` and
  `std_bare.cy` (2026-10-20).
- round.X: the oracle's built-in round and this folder's, in the oracle and through KAYO, give the same
  4,795 answers (bins and decis, every mode, whole and to 0, 1, 2, 3, 6 and 20 places); with the value
  and places read from the command line, Precog proves every one of round.cy's sites. Both are in KAYO's own tests against this
  folder (`kayo/compiler/tests/examples_cyborgpl_std.txt`; `inventory +unicode`, as it uses `char.%point`
  itself).
- In the oracle, each of the six beside the oracle's own built-in std (a copy of this folder under
  another prefix), over 820 cases (empty text, separators at the ends and side by side, overlapping
  finds, `é`, `🍎`), printing the same; and the same cases built by KAYO against this folder, written as
  a user writes them (`std::str.split(lend $s, at: lend $p)`), printing what the oracle's built-in std
  prints.
- Through KAYO, with the text read from the command line, so Precog has to prove std's sites for any
  text rather than by running the program on one. Rerun at KAYO 730f09df, once Precog counted argv's
  `ptr.read` as outside input (until then it had not, so the earlier "all proven" was unconfirmed):
  Precog "ran the program over what its inputs allow", and all 49 of std's sites in that program are
  proven, none checked at run time. 36 are proven by layer 2, from std's own code alone. 11 are
  proven by layer 3 ("no input reaches it with a bad value"), so they hold for any text this program
  reads but rest on the calls it makes (it calls `str.at` only at position 2). 2 are proven because
  "the position is always inside".
- The case changes (2026-10-24; rerun 2026-10-26 with the limb marks, KAYO 82185f15+), over 54 texts chosen for their edges
  (`ß`, `ŉ`, `ǅ`, `ﬀ`, `İ`, Greek sigma beside apostrophes and accents, `I` and `j` with marks above and
  below): `.ascii`, `.simple` and `.full`, with and without `lang:`, give the oracle's built-in std's 756
  answers, in the oracle and through KAYO. A wider sweep of final sigma, `Σ` beside 816 characters
  (every one both cased and case-ignorable, a sample of the rest), through KAYO: all 3,264 as Table 3-17

  `lang:`: every one of std's sites proven, none checked at run time. `examples/keys.cy` and
  `collections.cy`, built by KAYO against this folder, print their `.out`.
- An empty `part`, `at` or `from` is refused when building if written, and stops the program where it
  is passed if worked out at run time (exit 101), as the oracle does.

## Provisional

Each is a choice the record does not settle, dated, with the alternative. Each is an open question.

- **2026-10-14 — replace goes left to right and never looks inside what it put in**
  (`"aaa"` from `"aa"` to `"b"` is `"ba"`); split keeps empty pieces (`",a"` at `","` is `str.empty`
  and `"a"`); join of an empty list is `str.empty`. All as the oracle does; shown to the owner
  unasked, 2026-10-14, and nothing came back against them.
- **2026-10-20 — `places:` is `i32[min: 0]`**, so a negative one is refused when written and checked
  where it is passed when worked out; the oracle's built-in refuses it when the call runs. (It was
  `decimals` until the 2026-10-20 sweep.)
- **2026-10-24 — `lang:` left out is `root`**: `.full(lend $s)` is `.full(lend $s, lang: std::casing.root)`,
  as design claude picked for the oracle (its README). The alternative: no version without `lang:`, so every
  full case change names its language.
