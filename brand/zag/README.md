# Zag logo

The owner chose this on 2026-10-14: a light-to-blue gradient cloud with "ZAG" in yellow.

| File | What it is |
| --- | --- |
| `logo.svg` | The logo, cropped to the cloud |
| `logo-512.png`, `logo-1024.png` | The same, as transparent PNGs |
| `logo-square.svg` | The logo centred on a transparent square, for avatars and icons |
| `logo-square-512.png`, `logo-square-1024.png` | The same, as PNGs |
| `social-preview.png` | 1280 × 640, the logo and the tagline on a blue sky, for GitHub's Social preview setting |

- **Cloud:** a vertical gradient from `#8FD3FF` at the top to `#1F6FDB` at the bottom.
- **Letters:** `#FFD43B` with a `#1757B0` edge, 7 units wide.
- **Use:** one logo at every size. A more detailed illustration may follow, as artwork rather than a second logo.

The letters are "ZAG" set in Bungee and turned into outlines, so the logo needs no font to display. Bungee is copyright 2023 The Bungee Project Authors (https://github.com/djrrb/Bungee), under the SIL Open Font License 1.1, which allows this use.

The tagline in `social-preview.png` is set in Fredoka, also under the SIL Open Font License 1.1 (copyright 2016 The Fredoka Project Authors, https://github.com/hafontia/Fredoka-One).
