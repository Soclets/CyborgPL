# Graft (a possible name, not chosen)

A draft mark for the name Graft, which the owner weighed on 2026-10-17 ("graft would be shorter, and it would
be one syllable. Though, I don't know how the logo would go"). CyborgPL keeps its name and its C-with-`:=`
logo; this is kept only in case.

- `leaf.svg` / `leaf-512.png`: a leaf split along its stem line, living veins on one half and circuit traces
  ending in solder pads on the other: living joined with machine, which is what a graft (and a cyborg) is.
  Drawn by design claude; the owner: "That's good, but there's no syntax telling, which I guess is fine.
  Python has a good logo, but no syntax either. Save that shit".

Considered and dropped the same day: a G wrapping `:=` (the owner: "It's just not beatable, unless we make
an entirely new logo for Graft").
