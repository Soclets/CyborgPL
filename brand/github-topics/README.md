# GitHub topic pages

Drafts for [`github/explore`](https://github.com/github/explore), which gives a topic page
(`github.com/topics/cyborgpl`) its description and logo. One folder per topic, as that repo
wants them: `index.md` (short description at most 130 characters, no emoji; body at most 1,000
characters) and a 288×288 PNG under 75 kB named after the topic.

Not submitted: a topic page lists public repositories only, and `github/explore` curates topics
that repositories already use widely, so the pull request waits until CyborgPL is public. Opening
it is the owner's call. One pull request per topic.
