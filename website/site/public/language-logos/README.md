# Language artwork

Original files retrieved on 2026-10-03, displayed at a smaller size with their
colours, shape and aspect ratio preserved. Their own artwork and trademark terms
apply; they are not relicensed under the website code's licence. Visitor-facing
credits and links are in More → Logo credits.

- `nerve.svg` is generated by copying `brand/nerve/mark-black.svg` (the R from the NERVE wordmark) without changes.
  The Nerve project mark is copyright 2026 Tankun Sriket; see the project's
  [licence page](https://nerve-lang.com/licence) for the names and mark.
- `rust.svg` comes from the official
  [rust-lang/rust-artwork repository](https://github.com/rust-lang/rust-artwork/blob/main/logo/rust-logo.svg).
  Owned by the Rust Foundation, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
  [Artwork licence](https://github.com/rust-lang/rust-artwork/blob/main/logo/README.md)
  and [trademark terms](https://rustfoundation.org/policy/rust-trademark-policy/).
- `go.svg` is the unaltered [front-facing Gopher](https://go.dev/images/gophers/front.svg),
  the Go project's mascot by Renee French. [Creator and licence](https://go.dev/blog/gopher):
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
  This is the mascot artwork, distinct from the Go wordmark logo.
- `python.svg` is the unaltered official [two-snakes device](https://s3.dualstack.us-east-2.amazonaws.com/pythondotorg-assets/media/files/python-logo-only.svg),
  by Tim Parkin, with rights assigned to the Python Software Foundation.
  [Official downloads](https://www.python.org/community/logos/),
  [designer and usage information](https://www.python.org/psf/trademarks-faq/), and
  [PSF trademark terms](https://www.python.org/psf/trademarks/).
  The UI places a separate trademark symbol beside it without altering the asset.
